# Аналитика и экспорт для ИИ

Producer Sales Helper не отправляет данные в ИИ сам. Он собирает выгрузку, которую вы осознанно копируете или скачиваете и отдаёте модели: ChatGPT, Claude, Gemini, локальной модели — любой.

Есть три формата и один полный бэкап.

| Формат | Где взять | Для чего |
| --- | --- | --- |
| **AI-отчёт (Markdown)** | Аналитика → **AI-отчёт** | Читаемый отчёт с таблицами и готовым промптом. Лучший вариант для чата |
| **AI JSON** | Аналитика → **Скачать JSON** | Структурированные данные для моделей и скриптов |
| **CSV** | Аналитика / Настройки → CSV | Таблицы, Excel, Google Sheets, свои расчёты |
| **Бэкап JSON** | Настройки → Скачать бэкап | Восстановление приложения, не для ИИ |

---

## 1. AI-отчёт

**Аналитика → выберите период → AI-отчёт → Сформировать.**

Откроется предпросмотр. Внутри:

1. Ключевые показатели за период и сравнение с предыдущим.
2. Динамика по месяцам за 12 месяцев.
3. Воронка: сколько сделок дошло до каждого этапа и конверсия.
4. Источники: выручка, доля, оплаченные и открытые сделки.
5. Типы лицензий.
6. Топ клиентов.
7. Открытый пайплайн: сумма, вероятность, взвешенная сумма, дней в этапе, следующее действие.
8. Задачи: просроченные, на сегодня, на 7 дней.
9. Активность и ручные KPI: аутрич, ответы, звонки, прослушивания, подписчики, реклама.
10. Риски и наблюдения: просадки, концентрация, сделки без движения.
11. **Готовый промпт для ИИ.**

Кнопки:

- **Копировать** — весь Markdown в буфер обмена.
- **Скачать** — файл `psh-report-YYYY-MM-DD.md`.

### Как использовать

1. Сформируйте отчёт за месяц (или другой период).
2. Скопируйте целиком или скачайте `.md`.
3. Вставьте в чат с ИИ. Промпт уже в конце отчёта — отдельно ничего писать не нужно.
4. Если модель просит уточнить — отвечайте, но не удаляйте таблицы: в них контекст.

Пример:

```text
[вставьте весь отчёт]

Дополнительно: я работаю в нише trap/drill, средний чек $300,
хочу выйти на $2 000 в месяц. Что делать в ближайшие 30 дней?
```

## 2. AI JSON

**Аналитика → Скачать JSON.**

Файл `psh-ai-YYYY-MM-DD.json` содержит:

```json
{
  "meta": { "tool": "Producer Sales Helper", "period": { "...": "..." } },
  "summary": { "revenue": 0, "won": 0, "lost": 0, "winRate": 0, "pipeline": 0 },
  "previous": { "...": "..." },
  "monthly": [{ "month": "2026-01", "revenue": 0, "won": 0, "lost": 0 }],
  "funnel": [{ "stage": "lead", "label": "Лид", "count": 0, "conversion": 0 }],
  "sources": [{ "source": "Telegram", "revenue": 0, "won": 0, "open": 0 }],
  "licenses": [{ "license": "Exclusive", "revenue": 0, "count": 0 }],
  "topClients": [{ "name": "…", "revenue": 0, "deals": 0 }],
  "pipeline": [{
    "title": "…", "stage": "Переговоры", "amount": 0,
    "probability": 50, "weighted": 0, "daysInStage": 12
  }],
  "tasks": { "counts": { "...": 0 }, "overdue": [], "today": [], "week": [] },
  "activity": { "total": 0, "byType": {}, "manualKpis": {} },
  "insights": ["…"],
  "aiPrompt": "…"
}
```

JSON удобно давать моделям с большим контекстом или загружать в свои скрипты. Промпт лежит в поле `aiPrompt`.

Пример запроса:

```text
Ниже JSON из моей CRM. Проанализируй:
1) где просадка воронки;
2) какие 3 сделки закрывать первыми и почему;
3) какие источники дают риск концентрации;
4) какие 5 действий на неделю.

[вставьте JSON]
```

## 3. CSV

CSV — для таблиц, а не для чата. Файлы используют `;` как разделитель и BOM, поэтому корректно открываются в Excel и Google Sheets с русской локалью.

- **Сделки:** ID, название, клиент, этап, сумма, валюта, вероятность, лицензия, источник, даты, биты, заметки.
- **Клиенты:** имя, роль, Telegram, email, страна, источник, теги, последний контакт.
- **Задачи:** срок, повтор, статус, напоминание, клиент, сделка.
- **Биты, активности, KPI** — из соответствующих разделов или через полный бэкап.

## 4. Готовые сценарии

### «Где я теряю деньги?»

Сформируйте AI-отчёт за последние 3 месяца. Спросите:

```text
Разбери отчёт как sales-директор. Найди 3 главные утечки денег:
1) этап воронки с худшей конверсией;
2) сделки, которые зависли и не имеют следующего действия;
3) источники/клиенты, создающие зависимость.
Для каждой утечки — конкретное действие на этой неделе и метрика, по которой
проверить результат. Не выдумывай цифры, которых нет в отчёте.
```

### «Что делать на неделе?»

```text
На основе отчёта составь план на 7 дней: не больше 5 действий в день,
сначала сделки с наибольшей взвешенной суммой и ближайшим сроком.
Для каждого действия укажи сделку, клиента и готовый текст сообщения.
```

### «Напиши фоллоу-апы»

```text
Возьми сделки из раздела «Открытый пайплайн» без следующего действия.
Напиши по одному короткому сообщению в Telegram для каждой:
без давления, с конкретным поводом и одним вопросом в конце.
```

### «Пересмотри цены»

```text
Сравни средний чек, типы лицензий и win rate. Предложи 2–3 варианта
пакетирования и цен для битмейкера. Оцени, какой вариант меньше всего
рискует текущей выручкой. Учти, что данных может быть мало — скажи, чего не хватает.
```

### «Куда расти»

```text
Найди клиентов, которые дают больше всего выручки, и клиентов с высоким
потенциалом, но малым числом сделок. Предложи стратегию на 3 месяца:
кого удерживать, кого развивать, от кого отказаться.
```

## 5. Как часто выгружать

- **Раз в месяц** — базовый ритм: отчёт за месяц, сравнение с прошлым, план.
- **Раз в неделю** — короткий JSON или отчёт за 30 дней, чтобы не терять импульс.
- **Перед переговорами** — выгрузите пайплайн и топ клиентов, попросите подготовить аргументы.
- **После крупной сделки** — зафиксируйте, что сработало: источник, тип лицензии, цикл.

Не выгружайте чаще, чем меняются данные: отчёт за один и тот же день не даст новой информации.

## 6. Приватность

В отчётах и JSON есть:

- имена клиентов и контакты;
- суммы сделок и выручка;
- заметки;
- названия битов.

Это коммерческая тайна. Поэтому:

- не публикуйте выгрузки в открытых чатах и тредах;
- в ChatGPT/Claude/Gemini отключите обучение на ваших данных, если это доступно в настройках;
- для чувствительных клиентов обезличьте имена перед отправкой;
- не отправляйте бэкап целиком, если достаточно отчёта;
- помните, что публичный репозиторий не содержит данных, а Gist — содержит; не делайте Gist публичным.

---

## 7. Ограничения

- ИИ не знает контекст, которого нет в выгрузке: репутацию клиента, устные договорённости, ваши цели. Добавляйте это текстом.
- Модель может ошибаться в арифметике. Сверяйте ключевые цифры с приложением.
- Прогнозы — это гипотезы, а не гарантия. Проверяйте на коротких циклах.
- Отчёт не заменяет бухгалтерию и юридические документы.
- Если данных мало, честный ответ модели — «недостаточно данных». Это нормально: добавьте сделки и активность.
